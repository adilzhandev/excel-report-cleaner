# Excel Report Cleaner

Учебный pet-проект: берёт грязную табличную выборку и выдаёт настоящий
Excel-отчёт (`.xlsx`) с очищенными данными и сводкой. Задача — та же,
с которой сталкивается любой аналитик/стажёр, готовящий отчётность
в Excel: данные приходят из разных источников вразнобой, и перед тем
как их анализировать, нужно привести всё к единому виду.

## Что делает

Вход — `data/raw_data.csv`: 30 строк "записей о зачислении на курсы",
специально с шумом:
- три разных формата даты (`2024-01-15`, `15.01.2024`, `2024/01/16`);
- разный регистр названий курсов (`Excel продвинутый` / `excel ПРОДВИНУТЫЙ`);
- лишние пробелы в ФИО;
- пропущенные баллы и посещаемость;
- некорректные баллы вне диапазона 0-100 (`120`, `-5`, `102`);
- дубли записей (тот же студент/курс/дата под разным `student_id`);
- полностью пустая строка и строки без имени/курса.

`clean.py` пошагово:
1. Приводит ФИО и названия курсов к единому виду (словарь канонических
   названий — не `.capitalize()`, чтобы не сломать `SQL` в `Sql`).
2. Парсит дату по трём известным форматам в единый `YYYY-MM-DD`.
3. Переводит `score`/`attendance_pct` в числа, обнуляет значения вне 0-100.
4. Удаляет строки без ключевых полей (имя/курс) и дубли по
   (имя, курс, дата зачисления).
5. Считает сводку по курсам (студентов, средний балл, средняя
   посещаемость) и выгружает всё в `report.xlsx` — два листа:
   "Очищенные данные" и "Сводка".

## Стек

Python 3 + pandas + openpyxl. Без Flask/API/классов — это одноразовый
скрипт для конкретной задачи, а не приложение.

## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate   # опционально
pip install -r requirements.txt
python3 clean.py
```
На выходе — `report.xlsx` в корне проекта и лог в консоли: сколько
строк прочитано, сколько выброшено (битых/дублей), сводка по курсам.

## Пример вывода

Из 30 строк остаётся 26 (2 битые, 2 дубля):

```
                      course  students  avg_score  avg_attendance
0  Python для анализа данных         9       77.6            83.9
1         SQL для начинающих         9       70.3            73.1
2          Excel продвинутый         8       80.8            87.2
```

Проверено вручную: скрипт не падает на пустом файле (только заголовок).

## Почему так

- **Дубли ищем по (имя, курс, дата), а не по `student_id`** — в реальных
  данных одна и та же запись может попасть в выгрузку дважды под разными
  id (повторный ввод, повторная синхронизация). ID — не гарантия
  уникальности факта.
- **Некорректные баллы не удаляют всю строку** — обнуляется только само
  значение (`NaN`), остальные поля строки (имя, курс, дата) годные и не
  должны пропадать из-за одной битой цифры.
- **Явный словарь канонических названий курсов**, а не автоматическое
  приведение регистра — потому что автоматика ломает аббревиатуры
  (`SQL` → `Sql`), а с небольшим фиксированным списком курсов словарь
  проще и надёжнее.
